# Pellum · Gestão estética

Piloto em https://aura-piloto.vercel.app/ — o endereço antigo está mantido durante a mudança de marca.

A versão atual usa Supabase Auth/Postgres e frontend estático na Vercel. O código atual está na branch `security/application-review`, com revisão aberta; a branch `main` ainda contém a versão histórica ChatGPT/D1. Não republicar essa versão antiga.

GitHub: https://github.com/joaoaquino-dev/pellum . Projetos Supabase e Vercel: `pellum`.

Leia [a configuração atual](standalone/README.md) e [a revisão de segurança](security/REVIEW-2026-10-28.md) antes de usar dados reais. Publicação do piloto não significa aprovação para dados reais.

As referências internas `aura_*`, os caminhos `public/aura` e as migrações aplicadas são mantidos por compatibilidade. A identidade apresentada no aplicativo é Pellum.
